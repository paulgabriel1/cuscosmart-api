PASO 1. COPIAR EL PROYECTO A LA PC
----------------------------------
  1. Conecta el SSD "EXTERNO PAC".
  2. Abre la carpeta CuscoSmart-IA del SSD.
  3. Selecciona las carpetas  cuscosmart-api  y  cuscosmart-web
     -> Ctrl + C
  4. Ve al ESCRITORIO de la PC -> Ctrl + V
  5. Espera a que termine de copiar. Ya puedes desconectar el SSD.

  (Trabaja siempre desde el Escritorio, NO directo desde el SSD:
   es mas rapido y no se corrompe si se desconecta. Ademas, si usas
   "git" dentro del SSD sale "dubious ownership"; en el Escritorio no.)


PASO 2. PRENDER MYSQL
---------------------
  Abre "XAMPP Control Panel" -> en la fila MySQL clic en START
  -> debe ponerse VERDE. No cierres XAMPP.


PASO 3. ABRIR POWERSHELL
------------------------
  Tecla Windows -> escribe  powershell  -> Enter.
  Pega los comandos de abajo UNO POR UNO y presiona Enter.
  Espera a que termine cada uno antes de pegar el siguiente.

  Si sale "npm.ps1 no se puede cargar ... ejecucion de scripts":
      Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
  (escribe S y Enter) y vuelve a intentar.


PASO 4. PREPARAR Y PRENDER LA API   (ventana 1)
-----------------------------------
  cd $HOME\Desktop\cuscosmart-api
  npm install
  Copy-Item .env.example .env
  node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"

  -> Copia el texto largo que salio.
  notepad .env
  -> En la linea  JWT_SECRET=  borra lo que hay despues del "=" y pega
     tu texto. Guarda (Ctrl + S) y cierra el Bloc de notas.

  npm run db:reset
  -> Debe terminar con:  atractivos 27 ... Base cuscosmart_db recreada.

  npm run dev
  -> Debe decir:  Conectado a MySQL  /  API en http://localhost:3000/api/v1
  -> NO CIERRES ESTA VENTANA.


PASO 5. PREPARAR Y PRENDER LA WEB   (ventana 2: abre OTRO PowerShell)
---------------------------------
  cd $HOME\Desktop\cuscosmart-web
  npm install
  npm run dev
  -> Debe decir:  Local: http://localhost:5173/
  -> NO CIERRES ESTA VENTANA.


PASO 6. ABRIR LA PAGINA
-----------------------
  En Chrome o Edge:   http://localhost:5173

  Usuarios de prueba (escribe el correo y la contrasena en "Ingresar"):
     Administrador:  admin@cuscosmart.pe   /  Admin12345
     Turista:        ana@mail.com          /  Turista123

  Documentacion de la API (para el profe):  http://localhost:3000/api/v1/docs


LAS SIGUIENTES VECES EN LA MISMA PC
-----------------------------------
  1. XAMPP -> Start MySQL
  2. Ventana 1:  cd $HOME\Desktop\cuscosmart-api   y luego   npm run dev
  3. Ventana 2:  cd $HOME\Desktop\cuscosmart-web   y luego   npm run dev
  4. Abrir http://localhost:5173
  (Ya no hace falta npm install ni .env ni db:reset.)


TRAER LA ULTIMA VERSION DE GITHUB (si tienes acceso al repo)
------------------------------------------------------------
  Las carpetas ya vienen conectadas a GitHub. En cada una:
     git pull
     npm install
  Si cambio la base de datos:  npm run db:migrar  (en la API, NO borra tus datos)
                               npm run db:reset   (borra todo y deja los datos de ejemplo)


ACTUALIZAR ESTE SSD CON TUS CAMBIOS (para pasarselo a otro)
------------------------------------------------------------
  Copia de nuevo las carpetas del Escritorio al SSD y reemplaza.
  Puedes BORRAR antes las carpetas node_modules de cada proyecto
  (pesan mucho y se vuelven a crear con npm install).
  NO compartas tu archivo .env.


SI ALGO FALLA
-------------
  "No se pudo conectar con la API"   -> la ventana 1 esta cerrada o con error
  "ECONNREFUSED" / no conecta MySQL  -> XAMPP: Start en MySQL
  MySQL no arranca (puerto 3306)     -> Administrador de tareas: finalizar
                                        mysqld.exe y Start otra vez
  "Faltan variables en .env"          -> no hiciste el paso 4 (.env)
  "Cannot find package ..."           -> falta  npm install
  "EADDRINUSE 3000" o "port 5173"     -> ya esta abierto en otra ventana
  Solo hay 14 lugares / faltan fotos  -> npm run db:reset y reinicia la API
  "Demasiados intentos"               -> espera 15 min o reinicia la API
  Boton de Google en gris             -> normal, es opcional (ver guia)
  Mapa gris                           -> falta internet

  Guia completa con mas detalles:
     cuscosmart-api\docs\INSTALACION.md  (abrela con VS Code o en GitHub)
