NECESITAS: XAMPP, Node.js (LTS), Git e internet.

---------------------------------------------------------------------
PRIMERA VEZ EN UNA PC
---------------------------------------------------------------------
1. Descargar (o copiar las 2 carpetas del USB al Escritorio):
     cd $HOME\Desktop
     git clone https://github.com/paulgabriel1/cuscosmart-api.git
     git clone https://github.com/paulgabriel1/cuscosmart-web.git

2. XAMPP -> Start en MySQL (se pone verde).

3. Ventana 1 de PowerShell (API):
     cd $HOME\Desktop\cuscosmart-api
     npm install
     Copy-Item .env.example .env
     node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
     notepad .env        <- pega el texto largo en JWT_SECRET= y guarda
     npm run db:reset    <- debe decir "atractivos 27"
     npm run dev         <- NO cierres esta ventana

4. Ventana 2 de PowerShell (web):
     cd $HOME\Desktop\cuscosmart-web
     npm install
     npm run dev         <- NO cierres esta ventana

5. Abrir http://localhost:5173

---------------------------------------------------------------------
LAS SIGUIENTES VECES (traer lo ultimo de GitHub)
---------------------------------------------------------------------
  XAMPP -> Start MySQL
  Ventana 1: cd $HOME\Desktop\cuscosmart-api  -> git pull -> npm install -> npm run dev
  Ventana 2: cd $HOME\Desktop\cuscosmart-web  -> git pull -> npm install -> npm run dev
  Si cambio la base: npm run db:migrar (no borra datos) o npm run db:reset (datos limpios)

SI ALGO FALLA
---------------------------------------------------------------------
  "npm.ps1 no se puede cargar"       -> Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
  "No se pudo conectar con la API"   -> la ventana 1 esta cerrada o con error
  ECONNREFUSED / no conecta MySQL    -> XAMPP: Start en MySQL
  "Cannot find package ..."          -> falta npm install
  "Faltan variables en .env"         -> repite el paso 3 (.env)
  Solo 14 lugares / faltan fotos     -> npm run db:reset y reinicia la API
  Mas soluciones: docs\INSTALACION.md (seccion 7)

  NO compartas tu archivo .env (tiene tus claves).
